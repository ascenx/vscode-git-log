# Repository conventions

- All product UI copy must be English, including labels, tooltips, accessibility labels, loading states, and errors.
- Format product dates and relative times in English regardless of the editor or system language.
- Calendar-based filters use the UI's local time zone, including daylight saving transitions, even when the extension host is remote.
- Preserve repository content such as commit messages, author names, and paths in its original language. Translated documentation may remain translated.
